# 多站点架构

## 目标

本仓库统一管理成都、北海、深圳和阿里云节点的设计与期望状态。每个家庭站点应能在云节点不可用时独立上网和本地管理。

## 分层

```text
Git / Pull Request
  ├─ Inventory：站点、网络、主机和服务事实
  ├─ OpenTofu：可替换的 PVE VM/LXC
  ├─ Ansible：操作系统与 K3s 初始化
  └─ Flux：Kubernetes 应用持续同步
```

PVE 宿主机、OPNsense、物理网络、存储和数据盘不接受无人值守自动变更。

## 站点原则

- 阿里云可作为 WireGuard Hub，但不是家庭网络的单点依赖。
- 同一 VLAN ID 在各站点保持相同语义。
- 跨站点优先发布站点汇总路由。
- 家庭网络与未来公司网络分别建模并隔离密钥。
